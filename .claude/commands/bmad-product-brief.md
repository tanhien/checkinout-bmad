Create or update the Product Brief document at `_bmad-output/product-brief.md`.

A Product Brief is a 1-2 page executive summary used in BMAD Phase 1 (Analysis). It must be confirmed by the user before Phase 2 begins.

Steps:
1. Read `_bmad-output/full-plan.md` for project context
2. Read `CLAUDE.md` for confirmed requirements
3. Generate `_bmad-output/product-brief.md` with these sections:
   - **Vision** — one paragraph, the "why" this product exists
   - **Target Users** — each user type with their primary pain point
   - **Value Proposition** — what makes this system better than alternatives
   - **Scope** — what is IN scope and explicitly what is OUT of scope
   - **Key Assumptions** — things we're treating as true without full validation
   - **Success Metrics** — how we'll know if the product is successful
4. Ask the user to review and confirm before proceeding to PRD creation
